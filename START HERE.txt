Tongkat Gaib Excel
========================
How to run each report

If this is your first time: unzip the folder, then double-click
TongkatGaibExcel.exe. You do not need to install Python.

PC requirements (Windows version, memory, Excel) are in SYSTEM DETAILS.txt.

If something looks wrong after a run, read "After you click Run" at the
bottom of this file before sending the workbook on.


First run (every report)
------------------------
1. Double-click TongkatGaibExcel.exe
2. Pick a report from the dropdown
3. Pick the source file the program asks for
4. If a mapping / master button lights up, pick that file too
5. Leave FILTERS empty for the usual monthly report
6. Choose where to save the .xlsx
7. Click Run Pipeline
8. On pivot reports, check the Summary line "Filter Applied:" before you
   use the numbers

Greyed-out buttons and grey FILTERS boxes are unused by that report.
They are not broken.


What each report needs
----------------------
  #  Report                         Files you pick
  -- ------------------------------ ------------------------------------------
  1  Report Summary Akumulasi       source + UKER / branch mapping
  2  Time Series Active User Qlola  source + mapping + master-data workbook
  3  Report Data Statis             source (often a .bin) + mapping
  4  Rincian Vol TF                 source only
  5  Rincian Portal BG              source only
  6  Report Vol Briva               source + mapping
  7  Report Giro                    monthly giro workbook + giro master
                                    (no mapping file)

Source files are usually .txt / .csv / .bin. Excel .xlsx / .xls is also
accepted. Report Giro uses Excel workbooks on both sides.

Your original files are only read. The program writes a new file to the
save path you chose.


FILTERS (SEGMENT, SOURCE, KW)
=============================
One box per dimension. A box this report does not use stays grey
("not used by this report").

  Empty box              = automatic. That report's usual monthly rule.
  Choose... / typed text = keep ONLY those values. The usual rule for
                           that box is switched OFF for this run.

Typing does not "add" a value on top of the usual report. It replaces
the usual rule. That is the part that catches people out — see
"The KORPORASI trap" under Report Data Statis.

Each live box lists the keywords that report accepts, and has Choose...
so you do not have to remember spelling. Switching report clears the
boxes.

Comma-separated for several values. Upper/lower case and extra spaces
do not matter. If your file has no such column, that filter does
nothing — the run still finishes.


1. Report Summary Akumulasi
---------------------------
What it does
  Totals FBI and volume (VOLUME_IN_IDR) by branch.

What you process
  A pipe-delimited extract plus the UKER / branch mapping workbook.

What is unique
  Needs mapping. No automatic SEGMENT / SOURCE / KW cut when the boxes
  are empty — you get every row the extract has.

FILTERS (live)
  SEGMENT: KONSUMER, MIKRO, SME
  SOURCE:  CMS, QCASH, QIB
  KW:      grey

Usual monthly run: leave the boxes empty.


2. Time Series Active User Qlola
--------------------------------
What it does
  Counts distinct users as active (frequency at least 5) vs not, by
  branch.

What you process
  Three files:
    1. Raw pipe-delimited .csv (SOURCE, ID, FREKUENSI, KODE_UKER, ...)
    2. UKER mapping workbook (used on the detail sheet)
    3. Master-data workbook (user ID -> branch for the Summary)

  On MASTER DATA STATIS MALANG workbooks the user ID is in ID_PRODUCT
  (not CIF). Summary counts users the master can map. Unmapped IDs stay
  on the detail sheet.

What is unique
  Needs mapping AND master data. Empty SOURCE box drops CMS
  automatically.

FILTERS (live)
  SEGMENT: KONSUMER, MIKRO, SME
  SOURCE:  CMS, QCASH, QIB     (empty = drop CMS)
  KW:      grey

Usual monthly run: leave the boxes empty.


3. Report Data Statis
---------------------
What it does
  Counts ID_PRODUCT per branch.

What you process
  A pipe-delimited extract (often saved as .bin) plus the UKER mapping.
  The region lives in a KW column.

What is unique
  Empty SEGMENT drops KORPORASI. Empty KW keeps KANWIL MALANG.
  This is the only report with a live KW box.

FILTERS (live)
  SEGMENT: KONSUMER, KORPORASI, MIKRO, SME
  SOURCE:  CMS, QCASH, QIB
  KW:      18 regions (Bandung, Banjarmasin, Denpasar, DKI, DKI2,
           KANWIL BANDAR LAMPUNG, KANWIL JAKARTA 3, KANWIL JAYAPURA,
           KANWIL MALANG, KANWIL PEKANBARU, Makassar, Manado, Medan,
           Padang, Palembang, Semarang, Surabaya, Yogyakarta)

Usual monthly run: leave all three boxes empty.

The KORPORASI trap
  Typing KORPORASI in SEGMENT does NOT mean "add corporate back in".
  It means "show me KORPORASI and nothing else".

    SEGMENT empty        -> everyone EXCEPT corporate  (usual report)
    SEGMENT "KORPORASI"  -> corporate ONLY

  To include corporate together with other segments, list every segment
  you want, for example: KORPORASI, KONSUMER, MIKRO, SME
  There is no "keep everything" shortcut: empty means the usual rule,
  not everything.

  A different region for one run: type or Choose... that KW value.


4. Rincian Vol TF
-----------------
What it does
  Totals AMOUNT_IN_IDR by branch.

What you process
  The volume extract only. No mapping workbook.

What is unique
  Empty SEGMENT drops Wholesale.

FILTERS (live)
  SEGMENT: Kecil, Wholesale     (empty = drop Wholesale)
  SOURCE / KW: grey

Usual monthly run: leave SEGMENT empty.


5. Rincian Portal BG
--------------------
What it does
  Totals AMOUNT_IN_IDR by branch.

What you process
  The Portal BG extract only. No mapping workbook.

What is unique
  No automatic cut. FILTERS stay grey — this report has no SEGMENT /
  SOURCE / KW choices to pick.

Usual monthly run: pick the file, save, Run Pipeline.


6. Report Vol Briva
-------------------
What it does
  Totals BRIVA volume (VOLUME_IDR) by branch. Each row is rounded up
  before summing. The Grand Total keeps cents so you can ROUND later
  in Excel if you want.

What you process
  The BRIVA extract plus the UKER mapping.

What is unique
  Empty SEGMENT keeps NONWHOLESALE only.

FILTERS (live)
  SEGMENT: NONWHOLESALE         (empty = keep NONWHOLESALE)
  SOURCE / KW: grey

Usual monthly run: leave SEGMENT empty.


7. Report Giro
--------------
What it does
  Copies this month's IDR balance onto each account in the giro master
  and saves a new copy. This is not a pivot.

What you process
  Two Excel workbooks:
    1. Monthly giro file (account number + SALDO IDR)
    2. Giro master (the original list is enough, for example
       DAFTAR REKENING GIRO TSPM.xls with JENIS, NO REK, PRODUK,
       OPEN DATE, SALDO)

  If SALDO UPDATE is missing, the program adds it. If the file already
  has SALDO UPDATE or a month column such as SALDO JUNI, that existing
  column is filled instead.

What is unique
  No mapping file. FILTERS stay grey.
  The master you pick is never overwritten. Deposito rows are skipped.
  Accounts missing from the monthly file stay blank. Historical SALDO
  is never changed. Balances are whole numbers with no commas.

Usual monthly run: pick both workbooks, choose the save path, Run.


After you click Run
-------------------
Pivot reports (everything except Giro) write a Summary sheet plus a
detail sheet. Summary rows follow the usual dashboard branch order so
you can paste codes and amounts. Codes missing from the mapping show
as UNMAPPED; the report still generates.

Always read "Filter Applied:" on the Summary. For Report Data Statis:

  KORPORASI (excluded); KANWIL MALANG (KW only)   <- usual report
  KORPORASI (only); KANWIL MALANG (KW only)       <- corporate-only cut

If that line is not what you meant, the numbers will not be either.

If a run fails, the popup says what happened and what to try. Common
fixes:
  - Close the output Excel file before running again
    (Windows will not overwrite an open file)
  - An empty extract (titles only, or nothing at all) pops "Empty file"
    and does not write a report
  - Column titles do not have to sit on the first row
  - Qlola Summary smaller than a hand pivot: unmapped IDs are left out
    of Summary on purpose; they are still on the detail sheet
  - Giro grew a new column: normal when you started from the original
    five-column register. SALDO is history. SALDO UPDATE is the fill

Typical source layout (text / csv / bin):

  KODE_UKER|SEGMEN|VOLUME_IN_IDR
  0001|Wholesale|1250000000000
