Tongkat Gaib Excel
========================

No Python install needed - just double-click TongkatGaibExcel.exe

How to run
----------
1. Double-click TongkatGaibExcel.exe
2. Select a workflow from the dropdown (listed in daily reporting order)
3. Select your source file (pipe-delimited .txt / .csv / .bin, or Excel for Giro)
4. If prompted: select your reference mapping file (.xlsx)
5. If prompted (Qlola / Giro): select the extra workbook
6. Choose where to save the output (.xlsx)
7. Fill in the FILTERS boxes only if you want to narrow this run (see below)
8. Click "Run Pipeline"

FILTERS (SEGMENT, SOURCE, KW)
----------------------------
One box per dimension, on every report. There are only two things to know:

  Empty box  = automatic. The report runs its own normal rules.
  Typed text = keep ONLY what you typed. Comma-separated for several values.

Each box shows what it does automatically when left empty, e.g.
"auto: drops KORPORASI". You never have to type that rule yourself, and you
never have to clear a box to get it.

Examples:
  - Report Data Statis: empty SEGMENT = drops KORPORASI as usual.
  - Time Series Active User Qlola: empty SOURCE = drops CMS as usual.
  - Time Series FBI Briva: empty SEGMENT = keeps NONWHOLESALE as usual.
  - Type "RITEL, KORPORASI" in SEGMENT = keep only those two, this run only.

Matching ignores upper/lower case and extra spaces. If your file has no such
column, the filter simply does nothing - it can never fail the run. Switching
workflow clears the boxes. The Summary sheet's "Filter Applied" line records
what the run actually used.

Workflows (dropdown order)
--------------------------
1. Report Summary Akumulasi (needs reference mapping)
2. Time Series Active User Qlola (needs reference + master data)
3. Report Data Statis (needs reference mapping; raw may be a .bin extract)
4. Rincian Vol TF
5. Rincian Portal BG
6. Time Series FBI Briva (needs reference mapping)
7. Report Giro (needs monthly giro workbook + giro master; no reference mapping)

Qlola (Workflow 2) — three input files
--------------------------------------
1. Raw pipe-delimited .csv (SOURCE, ID, FREKUENSI, KODE_UKER, ...)
2. UKER reference workbook (KODE_UKER -> MAIN_CODE for detail only)
3. Master-data workbook (ID -> MAIN_CODE for the Summary pivot)

For ``MASTER DATA STATIS MALANG`` workbooks, the Qlola user ID lives in the
``ID_PRODUCT`` column (not ``CIF``). The Summary counts users by the master
``MAIN CODE`` after VLOOKUP on ID — same as manual Excel step 4.

Report Data Statis (Workflow 3)
-------------------------------
Raw is pipe-delimited (often a .bin extract). Needs a UKER/unit mapping
workbook. Keeps KANWIL MALANG, drops SEGMEN KORPORASI by default, and reports
Count of ID_PRODUCT per branch. To include corporate accounts for one run, type
KORPORASI in the SEGMENT box; KANWIL MALANG is always applied.

Report Giro (Workflow 7) — two Excel workbooks
----------------------------------------------
1. Monthly giro source workbook (NO REK + SALDO IDR)
2. Giro master workbook (the file whose SALDO UPDATE column is filled in)

The master you pick is never overwritten. The updated copy is saved to the
output path you choose. Deposito rows are skipped. Accounts missing from the
monthly file are left blank. Balances are written as plain whole numbers
(format 0) - concatenated digits, no commas and no decimal point.

The FILTERS boxes work here too: they filter the monthly source, so a
filtered-out account keeps whatever its master cell already had. If your monthly
file only has NO REK and SALDO IDR, they simply do nothing.

Reference file column names
---------------------------
The program accepts common alternate headers (not only KODE_UKER):

  Branch lookup:  KODE_UKER, KODE UNIT, KANCA, KODE SUB KANCA, KODE KANCA, UKER, KODE UKER
  Branch code:    MAIN_CODE, MAIN CODE, KODE, KODE KANCA, KODE UNIT, UNIQUE CODE, KODE INDUK
  Branch name:    MAIN_BRANCH, MAIN BRANCH, BRANCH, DESC KANCA, DESC UNIT, SUB KANCA, NAMA UKER, DESCRIPTION

Multi-sheet Excel files are supported - it scans sheets until it finds a match.

Output
------
Creates an Excel report with a Summary sheet (and detail/audit data as applicable).
Report Giro writes an updated copy of the master workbook instead of a pivot.

Troubleshooting
---------------
- Close the output Excel file before running again (can't overwrite an open file)
- If you see "Pipeline failed", read the error - it lists which columns were found
- Codes missing from the reference show as UNMAPPED (report still generates)

Sample raw data format (your .txt / .csv file should look like this):

  KODE_UKER|SEGMEN|VOLUME_IN_IDR
  0001|Wholesale|1250000000000
