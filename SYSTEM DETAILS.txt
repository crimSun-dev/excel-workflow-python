Tongkat Gaib Excel
SYSTEM DETAILS
============================================================
What the program is, what your PC needs, and what the package contains.

How to run each report is in START HERE.txt. Read that first.


1. WHAT THIS PROGRAM IS
-----------------------
A Windows program that turns the team's usual source files into the
seven monthly Excel reports (or, for Giro, an updated master copy).

Unzip the folder and double-click TongkatGaibExcel.exe. Nothing else
is installed. Microsoft Excel is not required to process a file. You
only need Excel afterwards if you want to open the finished workbook.

The package is the program you run. It does not include development
files or source.


2. PACKAGE CONTENTS
-------------------
  START HERE.txt          How to run each report (files, filters, tips)
  SYSTEM DETAILS.txt      This file (PC requirements and behaviour)
  TongkatGaibExcel.exe    The program

That is the whole package.


3. MINIMUM PC REQUIREMENTS
--------------------------
  Operating system    Windows 10 or Windows 11, 64-bit
  Processor           Any 64-bit PC that already runs Windows 10/11
  Memory (RAM)        4 GB minimum
                      8 GB recommended if monthly files are large or
                      you keep Excel open at the same time
  Free disk space     About 60 MB for the unzipped program, plus room
                      for your source files and the Excel it creates
  Screen              Normal desktop or laptop display; a file-picker
                      window must be usable
  Network             Not required. Everything runs on this PC
  Python              Not required
  Microsoft Excel     Not required to run. Required only to open or
                      print the output workbook
  Microsoft Office    No add-in, macro, or particular Office version
                      is needed for processing

A first-time setup is: unzip, then double-click the .exe. There is no
installer wizard.


4. FILES IT CAN READ
--------------------
  Source extracts     .txt, .csv, .bin, and Excel .xlsx / .xls / .xlsm
  Mapping / master    Excel workbooks, including older .xls
  Output              Always a new .xlsx at the path you choose

Inputs are read only. A failed Giro run writes no output file, so you
never send a half-updated master.


5. WHAT YOU WILL SEE WHEN IT RUNS
---------------------------------
  - Buttons and FILTERS boxes that do not apply to the chosen report
    stay grey
  - Empty FILTERS = that report's usual monthly rule
  - Chosen or typed FILTERS = keep only those values for this run
  - Pivot reports include a Summary sheet with "Filter Applied:" so
    you can see what actually ran
  - If a required column cannot be found, the program stops and
    explains. It does not guess
  - If the output file is open in Excel, Windows will not overwrite it
    — close it or pick a different save path


6. WHAT IT WILL NOT DO
----------------------
  - Change the files you selected as inputs
  - Need an internet connection
  - Need Python, Visual Studio, or an Excel add-in
  - Process files on a phone, a Mac, or a 32-bit-only Windows PC


7. IF SOMETHING LOOKS WRONG
---------------------------
  Program will not start
      Confirm you are on Windows 10/11 64-bit. Unzip the whole folder
      first; do not run the .exe from inside the zip window.

  Run failed
      Read the popup. Pick the file that report actually uses
      (see START HERE.txt). Do not rename columns at random.

  Totals look low or high
      Read "Filter Applied:" on the Summary first. A typed FILTERS box
      keeps ONLY what you typed. Empty means the usual rule, not
      "everything".

  Computer feels slow on a huge file
      Close other heavy programs and retry. 8 GB RAM is more
      comfortable for large monthly extracts.

  Cannot save
      Close the output workbook in Excel, or choose a different path.
